# 新北市選舉輿情監測

這個服務會從新聞來源增量發現新文章，進行日期、相關性、正文品質與重複事件處理，並在每日固定時間產生摘要與寄送報告。

## 啟動

```bash
npm install
npm start
```

啟動後開啟 `http://localhost:3000`。伺服器必須持續執行，每 3 小時的增量排程才會生效。

## 排程與查詢設定

可在 `.env` 覆寫以下設定；完整範例見 `.env.example`。

```dotenv
CRAWL_KEYWORDS=新北市長,新北選舉,新北市議員 選舉,李四川 新北,蘇巧慧 新北,吳亞倫 新北
CRAWL_CRON=0 */3 * * *
REPORT_CRON=30 8 * * *
SCRAPE_MAX_ARTICLES=12
SCRAPE_RECENT_DAYS=3
```

- 增量爬取預設每 3 小時整點執行一次。
- 日報預設每天台北時間 08:30 執行。
- 兩個工作及手動更新共用執行鎖，不會同時重複爬取。

## 健康檢查

- `GET /api/crawl-runs?limit=20`：最近爬取狀態、發現數、新增數與錯誤。
- `GET /api/crawl-runs/:id/sources`：該次執行每組查詢、每個來源的成功、失敗與文章數。
- 儀表板每分鐘自動刷新文章及最近爬取狀態。
- `npm test`：執行日期、相關性、URL、來源與正文擷取測試。

## 資料品質規則

- 嚴格驗證發布年月日，抓完正文後再做一次新鮮度過濾。
- 新聞標題先通過新北選戰相關性門檻，再下載全文。
- 優先使用新聞頁 JSON-LD 的 `articleBody`，其次才使用媒體專屬正文區塊。
- URL 會移除追蹤參數；文章另存 `story_key` 供事件聚類與去重。
- `crawl_runs` 保存每次執行結果，避免來源失敗被整體成功訊息掩蓋。
